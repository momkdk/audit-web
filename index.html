Audit d'en-têtes

Analyse défensive des en-têtes de sécurité HTTP d'une réponse — collez-les, l'analyse se fait dans votre navigateur, rien n'est envoyé nulle part.
Pourquoi coller les en-têtes plutôt qu'entrer une URL ? Un navigateur ne peut pas lire les en-têtes d'un site tiers pour des raisons de sécurité (CORS). La version en ligne de commande (voir le dépôt) interroge directement le site. Ici, récupérez les en-têtes vous-même — onglet Réseau de votre navigateur, ou curl -I https://votresite.fr — et collez-les ci-contre. À utiliser sur vos propres sites, ou ceux que vous êtes autorisé à auditer.

En-têtes HTTP

Un en-tête par ligne, au format Nom: valeur. Les lignes sans « : » (ligne de statut HTTP) sont ignorées.
